## ما يقدّمه نِبراس

| الميزة | التفاصيل |
|--------|---------|
| محرك الاختبارات الذكي | 6 انواع اسئلة مع تصحيح بالذكاء الاصطناعي |
| المساعد الدراسي | محادثة سقراطية تفاعلية |
| متتبع الامتحانات | عداد تنازلي دقيق لكل امتحان |
| مؤقت بومودورو | تقنية التركيز مع اصوات محيطية |
| اصوات التركيز | مطر - نار - غابة - مقهى - امواج - نسيم |
| سحابي بالكامل | بياناتك محفوظة - سجّل من اي جهاز |
| عربي اولا | RTL كامل + دعم الانجليزية |
